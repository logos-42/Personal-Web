Fusion 项目 — 可控核聚变的工程闭环

Created on October 13, 2026

2026   ·   fusion   forge   simulation   ·   fusion

可控核聚变 Fusion 项目进行中，两条腿走路：Forge 做装置设计，fusion-sim 做输运与控制仿真。这篇把两条线的方法、验证数据和边界一次写清楚。

1. HUSHFUSION Forge — 电磁线圈设计闭环

问题

聚变装置的线圈设计长期依赖专家经验手工迭代：一次实验只产出一个设计，周期长，设计知识无法被后续复用。目标是把它变成「算法驱动的可学习闭环」。

六步闭环

参数化设计 → 磁场物理 → 目标函数 → 搜索 → 设计注册表 → 设计规则。

  • 磁场物理：圆环电流闭式解（完全椭圆积分 AGM）计算真空静磁场，并用独立分段 Biot–Savart 求解器交叉验证——两套实现互验，避免单栈偏差。
  • 目标函数：场强、镜比、可用场体积、纹波、造价与约束罚的组合。
  • 人工基线：Helmholtz 中央室 + 镜喉，中场平均场 1.0 T，作为机器搜索的对照。
  • 工程栈：Go 主栈 + 独立 Python 复核层；设计注册表把每次尝试沉淀为可复用规则。

等预算实验（Phase 0）

在相同评估预算下比较 4 种搜索方法 × 3 个 seed × 1,000 次评估，共 12,001 条记录，纯计算 5.5 秒。

  • 机器最优 score 1.381419 vs 人工基线 −0.290571，Δ = +1.672，3/3 seed 全胜。
  • 加入导体净空约束（≥ 0.05 m）后，Δ = +1.2395，可行记录 7,221 / 12,001。
  • 23 道验收门 + 跨语言 oracle 交叉校验，保证结果不是某一套实现的偶然产物。

边界（很重要）

v0.1 的结论只适用于真空静磁场设计：不含等离子体压强、抗磁性、平衡与有限 β。把它读成「聚变装置已优化」是错的，它优化的是线圈位形的静磁部分。

2. fusion-sim — 聚变数字仿真工作台

问题

验证现有 AI 仿真栈在本机能否跑通，并判断自研物理模型能否做成可训练、可验证的控制问题。

两条线

  • A 线（成熟栈接入）：TORAX 可微 1-D 输运 + Gym-TORAX（Gymnasium 控制环境）+ ITER ramp-up。
  • B 线（自研环境）：gym-μ-FRC v0，包含 μ 动力学 TD1–TD21、FRC 窗口 FC11b/FC5b、RMF 代价与 RL 环境；与 Lean 4 形式化逐条对齐，做 μ → 0 极限回归、多 seed 与穷举参考解对照。

技术栈：Python / JAX / Gymnasium；依赖钉死在 jax/jaxlib 0.4.38、torax 1.0.3、gymtorax 1.0.0，保证可复现。

门禁与「门齿测试」

make test 是硬性门禁：5 seeds × 400 回合训练 + 对照组 + 穷举参考解。为了确认门禁真的能抓错，还做了缺陷注入：

  • 让 μ 忽略 η → 7 条红；
  • 让 close_step 偏一步 → 1 条红；
  • 复原缺陷后全绿。

也就是说，测试不是摆设，它对这些具体错误敏感。

边界

不含实验数据、不做实验拟合。所有结论都是模型内的条件结论，不是电站级仿真，更不是实验验证。

3. 两条线怎么接起来

Forge 给出线圈位形，fusion-sim 提供输运与控制侧的可训练环境；长期目标是把两者放到同一个优化回路里。目前仍是两套独立系统：Forge 的搜索目标是静磁指标，fusion-sim 的环境是输运/控制指标，联合优化尚未收敛。

下一步与未解

  • 线圈—等离子体联合优化的收敛性：两套目标函数如何统一，是首要难题。
  • FRC 窗口（FC11b/FC5b）的实验验证：目前只有模型内结果。
  • 从真空静磁走向有限 β：需要引入压强、抗磁性与平衡约束。
