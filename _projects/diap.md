**DIAP**（Decentralized Interstitial Agent Protocol）：让任意两个智能体无需中心化信任锚点即可完成去中心化身份验证与通信的协议。

- **核心机制**：零知识证明 + 混合 P2P 栈 + 预言机驱动的身份认证与信任机制
- **论文**：[arXiv:2511.11619](https://arxiv.org/abs/2511.11619) — *DIAP: A Decentralized Agent Identity Protocol with Zero-Knowledge Proofs and a Hybrid P2P Stack*
- **代码**：[DIAP_TS_SDK](https://github.com/logos-42/DIAP_TS_SDK)（TypeScript）· [DIAP_Python_SDK](https://github.com/logos-42/DIAP_Python_SDK) · [DIAP_Rust_SDK](https://github.com/logos-42/DIAP_Rust_SDK)
- **生态**：DIAP-DAO（[Alou-DAO](https://github.com/logos-42/Alou-DAO)）、多智能体预言机（[MultiAgentOracle](https://github.com/logos-42/MultiAgentOracle)——只验证智能体逻辑、不验证数据的因果指纹机制）
